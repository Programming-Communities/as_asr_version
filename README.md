# Al Asr Centers - Next.js Islamic Platform

A modern, high-performance Islamic educational platform built with Next.js 16, TypeScript, and WordPress integration.

## Features

### 🚀 Core Features
- **Next.js 16.0.7** with App Router
- **TypeScript** for type safety
- **PWA** ready with offline support
- **Responsive Design** for all devices
- **5+ Themes** with dark/light mode
- **Infinite Scroll** with 100-post chunks

### 📱 Device-Specific Components
- Mobile/Tablet/Desktop optimized cards
- Device-aware ads components
- Responsive layouts and navigation

### 🔗 WordPress Integration
- WPGraphQL for efficient data fetching
- ACF (Advanced Custom Fields) support
- Dynamic header/footer from WordPress
- Comments and reactions via REST API

### 🎨 User Experience
- Skeleton loading states
- Smooth page transitions
- Reading progress bar
- Pull-to-refresh on mobile
- Slide-up post sheets

### 💬 Content Interaction
- WhatsApp-style reaction emojis
- Guest comments with captcha
- Social sharing buttons
- Bookmarking system
- Reading history

### 🍪 Privacy & Compliance
- GDPR-compliant cookie consent
- Cookie preference management
- Analytics integration
- Privacy-safe tracking

### 📊 Performance
- ISR (Incremental Static Regeneration)
- AVIF image optimization
- Route-level code splitting
- Workbox offline caching
- Lighthouse optimized
